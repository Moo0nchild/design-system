# SaborUPC · design-system

**Equipo:** Plataforma · **Dueño:** Deimis · **Puerto local:** 8085

Sistema de diseño mínimo: `tokens.css` con variables CSS (colores, tipografía, espaciado). **Solo UI, nada de lógica de negocio.**

## Cómo ejecutar

```bash
python -m http.server 8085
```

- http://localhost:8085/tokens.css → la hoja que consumen todos los micro frontends
- http://localhost:8085 → muestra visual de los tokens
